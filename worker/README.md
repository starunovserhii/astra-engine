# ASTRA Interpret Worker

Тонкий бэкенд-слой, который включает Claude в интерпретацию натальной карты —
реализация §11/§14 мастер-промпта ASTRA (AI INTERPRETATION ENGINE). Движок
(`src/`) по-прежнему сам считает всю астрономию/астрологию; этот сервис
только передаёт уже посчитанные данные в Claude API и возвращает текст.
Ключ Anthropic API хранится здесь как секрет и никогда не попадает в
браузер — именно поэтому это отдельный сервис, а не код на самой странице.

**Без этого шага сайт продолжает работать как раньше** — «Глубокая
расшифровка» на правилах (без AI) остаётся основной и включена по
умолчанию. AI-переключатель в этом разделе автоматически скрыт/неактивен,
пока `AI_BACKEND_URL` в `site/template.html` пустой.

## 1. Получить ключ Anthropic API

1. Зарегистрируйся или войди на https://console.anthropic.com
2. Создай API-ключ (раздел API Keys).
3. Обрати внимание на биллинг — каждый вызов Claude стоит денег
   (эндпоинт публичный, любой посетитель сайта может его дёргать; см.
   раздел «Защита от злоупотреблений» ниже перед тем как публиковать URL
   воркера широкой аудитории).

## 2. Установить Wrangler и авторизоваться в Cloudflare

```bash
cd worker
npm install
npx wrangler login   # откроет браузер для входа в твой Cloudflare-аккаунт
```

Аккаунт Cloudflare бесплатный, Workers на бесплатном плане достаточно для
демо-нагрузки (100 000 запросов/день).

## 3. Задать секрет (ключ Anthropic)

```bash
npx wrangler secret put ANTHROPIC_API_KEY
# вставь ключ, полученный на шаге 1, когда попросит — он никогда не
# попадёт в git и не будет виден в коде
```

## 4. (Опционально) поменять модель или разрешённый origin

Открой `worker/wrangler.toml` — там два обычных (не секретных) значения:

```toml
[vars]
ANTHROPIC_MODEL = "claude-sonnet-4-5"
ALLOWED_ORIGIN = "https://starunovserhii.github.io"
```

Смени `ALLOWED_ORIGIN`, если сайт будет жить на другом домене — иначе
браузер будет блокировать запросы по CORS.

## 5. Локальная проверка (без реального деплоя)

```bash
npm run dev
# в другом терминале:
curl -X POST http://localhost:8787/interpret \
  -H "Content-Type: application/json" \
  -d '{"points":[{"name":"Sun","sign":"Leo"}],"aspects":[],"label":"тест"}'
```

С настоящим ключом должен вернуться `{"text": "...", "model": "...", "style": "human"}`.

## 6. Деплой

```bash
npm run deploy
```

Wrangler выведет URL вида `https://astra-interpret.<твой-поддомен>.workers.dev`
— это и есть `AI_BACKEND_URL`.

## 7. Подключить к сайту

Открой `site/template.html`, найди строку:

```js
const AI_BACKEND_URL = '';
```

и впиши туда URL из шага 6 (без слэша на конце, например
`https://astra-interpret.твой-логин.workers.dev`). Пересобери сайт:

```bash
cd ..
npm run build:site
```

После этого в разделе «Глубокая расшифровка» появится активный
переключатель «Расшифровка с ИИ (Claude)» со стилями из §14 брифа
(Professional / Human / Psychological / Spiritual / Premium).

## Защита от злоупотреблений (важно для публичного сайта)

`/interpret` — открытый эндпоинт: единственная защита в коде — потолок
размера тела запроса (40 КБ) и проверка обязательных полей. Это НЕ защита
от кого-то, кто целенаправленно решит накрутить тебе счёт за Claude API.
Прежде чем давать реальному публичному трафику доступ к включённому
AI-переключателю, рассмотри один или несколько вариантов:

- **Cloudflare Rate Limiting** (Dashboard → Security → WAF → Rate limiting
  rules) — ограничить число запросов с одного IP в минуту.
- **Cloudflare Turnstile** — бесплатная защита от ботов, встраивается
  простым виджетом на фронтенде; воркер проверяет токен перед вызовом
  Claude. Не реализовано в этой версии — осознанное ограничение объёма,
  добавляется отдельным шагом при необходимости.
- **Дневной/месячный лимит трат** в биллинге Anthropic Console, чтобы
  верхняя граница расходов была гарантированно ограничена независимо от
  трафика.

## Архитектурные заметки

- Ответ не потоковый (не streaming) в этой версии — воркер ждёт полный
  ответ Claude и отдаёт его одним JSON. §41 брифа рекомендует streaming
  для AI-ответов; это осознанно отложено ради простоты и надёжности первой
  версии — при необходимости добавляется заменой `stream: false` на
  `stream: true` в запросе к Anthropic и проксированием SSE-потока через
  `Response(anthropicRes.body, ...)`, плюс парсер `content_block_delta`
  событий на фронтенде.
- Правило-ориентированная «Глубокая расшифровка» (без AI) остаётся
  основной и работает независимо от этого сервиса — AI-режим лишь
  дополняет её, никогда не заменяет как единственный источник текста
  (сайт обязан оставаться полностью рабочим даже без бэкенда).
